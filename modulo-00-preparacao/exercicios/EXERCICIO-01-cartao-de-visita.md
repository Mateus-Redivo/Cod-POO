# Exercício 01 — Cartão de visita

| Nível | Tempo estimado | Conceitos |
| --- | --- | --- |
| 1 de 3 | 15 min | `System.out.println`, comentários, compilar e executar |

## Objetivo

Escrever, do zero, o seu primeiro programa Java e conseguir compilá-lo e rodá-lo pelo terminal, sem copiar o `OlaTurma.java` do módulo.

## Requisitos

1. Crie um arquivo chamado `CartaoDeVisita.java` (nome da classe igual ao nome do arquivo).
2. O programa deve mostrar na tela: seu nome, sua cidade e uma frase sobre por que você está estudando programação.
3. Use uma linha em branco (`System.out.println();`) para separar o nome do resto.
4. Escreva pelo menos um comentário explicando alguma escolha sua: não vale comentar o óbvio.
5. Compile e execute **pelo terminal**, com `javac CartaoDeVisita.java` e `java CartaoDeVisita`. O botão "Run" do VS Code também funciona, mas o objetivo aqui é conseguir pelos dois caminhos.

## Exemplo de saída

```text
=================================
Maria Oliveira

Cidade: Cascavel - PR
Estudo Java para conseguir minha primeira vaga como desenvolvedora.
=================================
```

O conteúdo é seu; o formato pode variar. O que não pode faltar são as três informações e a linha em branco.

## Critérios de aceitação

- [ ] O arquivo se chama `CartaoDeVisita.java`, a classe se chama `CartaoDeVisita`, e compila sem erro
- [ ] Aparecem nome, cidade e o motivo de estudar
- [ ] Existe pelo menos um `System.out.println();` vazio separando blocos
- [ ] Existe pelo menos um comentário, e ele explica algo não óbvio
- [ ] Você compilou e executou pelo terminal ao menos uma vez

## Desafio opcional

Provoque um erro de propósito: apague um `;`, por exemplo. Anote em um comentário qual linha o `javac` apontou e qual foi a mensagem. Depois conserte.
